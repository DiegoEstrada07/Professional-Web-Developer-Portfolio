# Professional-Web-Developer-Portfolio
 Hi, I´am Diego Estrada a new web developer and this is my portafolio.

This is a personal portfolio created in React, designed to showcase my skills and projects as a web developer. Here, you'll find details about the projects I've worked on, my technical skills, and my experience in the web development world.

## Technologies Used

- **React** - JavaScript library for building interactive user interfaces.
- **HTML5 & CSS3** - Structure and styling of the page.
- **JavaScript** - Application logic.
- **React Router** - For navigation between different sections of the portfolio.
- **Styled Components** - For managing styles in React components.
- **Git & GitHub** - Version control and project repository.

## Features

- **Responsive Design**: The portfolio adapts to different screen sizes for mobile, tablet, and desktop views.

## Installation

1. **Clone the repository**:

   ```bash
   git clone https://github.com/DiegoEstrada07/Professional-Web-Developer-Portfolio

2. **Navigate to the project directory**:

    cd your-portfolio

3. **Install dependencies**:

    npm install

4. **Install react router dom**:

    npm install react-router-dom

## Running the Project

    To view the portfolio locally on your machine:

    npm start
